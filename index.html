📱 如何不用開 Gemini，直接從 iPhone 17 Pro 桌面秒開 V7？

本檔案已修復啟動自動彈窗問題（打開直達乾淨主畫面），並直接將下載檔名設為 index.html（免手動改名，可直接上傳 GitHub Pages 覆蓋）：

方法 1：30 秒免費產生固定網址 → 加入主畫面（最推薦）
  1. 點上方按鈕下載 V6.html 到手機「檔案」。
  2. 用 Safari 打開免費靜態託管站（例如 app.netlify.com/drop 或你的 GitHub Pages），把 V6.html 改名為 index.html 傳上去，取得你的專屬 `https://...` 網址。
  3. 在 Safari 打開該網址 → 點底部中間「分享」圖示 → 選「加入主畫面」，桌面上就會出現獨立的 `V5` App！
方法 2：iPhone「捷徑」直接綁定本機檔案（完全免網路託管）
  1. 將下載的 V6.html 存在 iPhone「檔案（On My iPhone）」資料夾。
  2. 打開 iPhone 內建「捷徑」App → 新增捷徑 → 加入動作「打開檔案（選擇 V6.html，使用 Safari 或 Koder 開啟）」→ 點分享選「加入主畫面」即可一鍵從桌面啟動！
